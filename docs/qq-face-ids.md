# QQ 表情 ID 大全（face id）

> 数据源：[SnowLuma](https://snowluma.github.io/zh/) 缓存的 QQ 系统表情目录（抓取于 2026-10-27 17:04），共 **299 个 face id**，另有 68 个 emoji 码点。
>
> 其中 **190 个**是编号大于 221 的新版表情 —— 网上流传的旧对照表基本都缺这一段，这份表是完整的。
>
> 编号会跳号（0~524 之间缺一部分），那是 QQ 已经下线的老表情，不是表漏了。
>
> **两种编号**：系统表情填 face id（如 `478`）；Unicode emoji 填**十进制码点**（如 🐛 = `128027`、😧 = `128551`）。下面列的 68 个 emoji 只是 QQ 表情面板里那套，**其他 emoji 只要知道码点也照样能贴**，不必在表里。

填在插件 `[emoji] emoji_pool` 里的就是下表的 **id** 列（十进制字符串）。

| 想做什么 | 怎么做 |
| --- | --- |
| 按名字找 id | 本页 `Ctrl+F` 搜中文名，或打开同目录的 `face-lookup.html` |
| 按 id 找名字 | 搜数字，或看下面「按编号排序」一节 |
| 验证真的贴上了 | 见下面「实测」一节的 `get_emoji_likes` 用法 |

## 实测：表里的 id 真能贴上

2026-10-25 在测试群一条消息上按类别各取一个，先 `set_msg_emoji_like`，再用
`get_emoji_likes` 逐个回查（`data.emoji_like_list` 非空才算真贴上）：

| id | 类别 | set 返回 | 回查 |
| --- | --- | --- | --- |
| `478` | 小黄脸 / 超级表情 | ok | ✅ 贴上 |
| `500` | QQ 黄脸（秋秋赏月） | ok | ✅ 贴上 |
| `512` | 限时表情（王者召唤） | ok | ✅ 贴上 |
| `320` | 超级表情（庆祝） | ok | ✅ 贴上 |
| `358` | MagicFace | ok | ✅ 贴上 |
| `9989` | emoji 码点（✅） | ok | ✅ 贴上 |
| `999999` | 不存在的 id | **ok** | ❌ 空 |

🔴 最后一行是重点：**`set_msg_emoji_like` 对不存在的 id 也返回 `ok`**，
光看返回值判断不了成败。回查要这样调：

```json
POST /get_emoji_likes   {"message_id": "<消息id>", "emoji_id": "478"}
-> data.emoji_like_list 有内容 = 真贴上；空数组 = 没贴上
```

## 三套编号别混

| 类型 | 填什么 | 例子 |
| --- | --- | --- |
| QQ 系统表情 / 表情包 | **face id（十进制）** | `478` = 对的对的 |
| QQ 的 emoji 表情 | **Unicode 码点（十进制）** | `9989` = ✅ |
| em 编号（`emCode`） | 只在本表里做对照，**不能填** | `100` 对应的 face id 是 `14` |

🔴 坑：填十六进制字面值（`2705`、`128536`）接口会返回 `ok`，但客户端贴出来是空白。

## 这份表怎么更新

QQ 出新表情后重跑一次即可：

```bash
python tools/gen_face_table.py
```

脚本自己选数据源，**不用 SnowLuma 也能用**：

| 你的环境 | 读哪个文件 | 备注 |
| --- | --- | --- |
| SnowLuma | 它的 `<SnowLuma>/data/sys-face-catalog.json` | 实时，永远最新 |
| NapCat / Lagrange / LLOneBot | 插件自带 `tools/face_catalog_snapshot.json` | 开箱即用，不装 SnowLuma 也行 |
| 两边都有 | 抓取时间更新的那个 | — |

- `--update-snapshot` 用实时目录刷新内置快照（需要有 SnowLuma 的环境）
- `--catalog <path>` 手动指定目录文件；`--check` 只看统计不写文件

> 🔴 表里的 id 是 **QQ 服务端下发的编号，跟用哪个网关无关**。但能不能贴出来，取决于
> 网关的 `set_msg_emoji_like` 实现 —— 换网关后建议先用 `get_emoji_likes` 抽查几个，再批量填进配置。
